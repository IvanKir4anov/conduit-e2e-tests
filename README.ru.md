# Conduit E2E tests (кратко на русском)

[Полная документация на английском](README.md)

Набор end-to-end тестов для [RealWorld Conduit](https://github.com/realworld-apps/realworld),
клона Medium с REST API и веб-интерфейсом. Стек: **Playwright + TypeScript**, Docker,
GitHub Actions.

Это демонстрационный проект, а не универсальный шаблон. Его цель показать, как строится набор
автотестов, которому команда доверяет: тесты изолированы, падения легко разбирать, окружение
под контролем, а красная сборка всегда означает реальную проблему.

## Что внутри

- **Тестируемое приложение** собирается из закреплённых коммитов исходных проектов (бэкенд
  ASP.NET Core, фронтенд Angular) и поднимается локально через Docker Compose. Внешние сервисы
  и секреты не нужны.
- **Слои:** типизированный API-клиент, Page Objects, фикстуры Playwright, фабрики уникальных
  тестовых данных.
- **25 тестов** уровня API, UI и гибридных (данные через API, поведение через UI): аккаунты,
  статьи, комментарии, лайки, подписки и лента, права доступа, гостевой режим. Плюс unit-тест
  фабрик тестовых данных.
- **Теги:** `@smoke` — критичный путь (6 тестов), `@regression` — остальные 19 тестов.
- **CI:** линтер и проверка типов, затем приложение в Docker, затем smoke как быстрый шлюз,
  затем regression. Ночной прогон строгий: каждый тест трижды, любой нестабильный (flaky)
  результат валит прогон, а упавший плановый прогон открывает issue.
- **Диагностика:** для каждого упавшего теста есть HTML-отчёт, trace, скриншот и видео.

## Быстрый старт

```bash
npm ci
npx playwright install chromium
npm run env:up      # собрать и запустить приложение на http://localhost:8080
npm test
```
